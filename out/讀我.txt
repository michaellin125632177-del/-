日三牙醫體系 · 班表看板更新工具
================================

這個資料夾是用來「每月產生新的班表看板」的。

怎麼用
------
Mac      按兩下  更新看板.command
Windows  按兩下  更新看板.bat

它會問你要產生哪一個月,輸入像 2026-11 這樣的格式,按 Enter。
跑完之後,這個資料夾裡會多出一個「上傳這個資料夾」,
把那整個資料夾拖到 Cloudflare Pages 就完成了。不用改任何檔名。

第一次使用
----------
電腦需要先裝 Python 3(免費):https://www.python.org/downloads/
Windows 安裝時請勾選「Add Python to PATH」。
其他需要的東西,程式會自己裝。

Mac 第一次按兩下如果跳出「無法打開」,
請在 更新看板.command 上按右鍵 →「打開」→ 再按一次「打開」。
這是 macOS 對網路下載檔案的預設保護,只要做一次。

這裡面有什麼
------------
更新看板.command / .bat   你要按的那個
build_roster.py           產生 Excel 出勤表
build_site.py             產生班表看板網頁
weekly.py                 五間院所的門診表資料 + 2026 國定假日

跑完會產生
----------
上傳這個資料夾/index.html       ← 要上傳到 Cloudflare 的就是這個資料夾
日三牙醫體系_統一出勤表.xlsx      完整版,九個分頁
日三牙醫體系_統一出勤表_醫師版.xlsx  只有醫師那五個分頁
班表看板_預覽.html               同看板內容,預覽用

要注意
------
1. 國定假日目前只到 2026 年底。跨到 2027 年之前要更新假日表,
   否則新年度會把國定假日排成上班日。這要改 weekly.py,請找負責人。
2. 醫師異動(新進、離職、固定門診時段改變)也要改資料再重跑,
   不是改網頁。改完 Excel 和看板會一起更新。
3. 不要自己編輯「上傳這個資料夾」裡的 index.html。
   下次重跑就會被蓋掉,而且會跟 Excel 對不起來。
