# 牙醫體系 統一出勤表

體系內各院所共用的月班表範本(班表 + 月結統計)。

| 檔案 | 說明 |
| --- | --- |
| `牙醫體系_統一出勤表_範本.xlsx` | Excel 範本。4 個分頁:說明 / 設定 / 班表 / 月結統計。已內建下拉選單、條件式格式與月結公式。 |
| `roster-spec.html` | 規格說明頁,給上級與各院所溝通用。 |
| `build_roster.py` | 產生 xlsx 的腳本。改代碼表或人員名冊後重跑即可重建範本。 |

六個分頁:說明 / 設定 / 班表 / 打卡匯入 / 出勤紀錄 / 月結統計。

## 設計重點

- 統一的是「欄位」與「班別代碼」,不是版面。醫師以診次計、醫護長與助理以工時計,共用同一套代碼。
- 月結統計以 `設定` 分頁的權重(排班工時 / 診次 / 計出勤)反推,改權重不必改公式。
- 有固定時段的代碼必須滿足 `應退 − 應到 − 休息 = 排班工時`,建置腳本會 assert 檢查。
- `出勤紀錄` 為 930 列(30 人 × 31 天)的法定紀錄,自動比對班表與打卡,判定正常 / 遲到 /
  早退 / 未打卡 / 假日出勤五種狀態。
- 加班採門檻制:預設超過排班工時 30 分鐘才認定,並無條件捨去到 30 分鐘。逐分鐘認定會把
  每天正常收尾的十幾分鐘全算成加班(實測範例資料:45.6 小時 vs 6.5 小時)。三個參數集中在
  `設定` 分頁的計算參數區。
- 加班時數為「實際工時 − 排班工時」,**未依勞基法第 24 條換算費率**,薪資須另行計算。
- `出勤紀錄` 分頁是為勞基法第 30 條的逐日紀錄設計的,但**必須每月另存唯讀封存檔**才算數
  (法定保存 5 年)。

## 重建方式

```bash
pip install openpyxl
python3 build_roster.py
# 產生公式後必須重算一次,否則公式沒有快取值
```

範例資料(院所、人員、班表內容)上線前請整批置換。
