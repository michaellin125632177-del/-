# 牙醫體系 統一出勤表

體系內各院所共用的月班表範本(班表 + 月結統計)。

| 檔案 | 說明 |
| --- | --- |
| `牙醫體系_統一出勤表_範本.xlsx` | Excel 範本。4 個分頁:說明 / 設定 / 班表 / 月結統計。已內建下拉選單、條件式格式與月結公式。 |
| `roster-spec.html` | 規格說明頁,給上級與各院所溝通用。 |
| `build_roster.py` | 產生 xlsx 的腳本。改代碼表或人員名冊後重跑即可重建範本。 |

## 設計重點

- 統一的是「欄位」與「班別代碼」,不是版面。醫師以診次計、醫護長與助理以工時計,共用同一套代碼。
- 月結統計以 `設定` 分頁的權重(排班工時 / 診次 / 計出勤)反推,改權重不必改公式。
- 全檔只有三處手填:員工編號、每日班別代碼、加班時數。
- 本表為「預排班表 + 月結統計」,**不能取代**勞基法第 30 條要求的逐日實際出勤紀錄。

## 重建方式

```bash
pip install openpyxl
python3 build_roster.py
# 產生公式後必須重算一次,否則公式沒有快取值
```

範例資料(院所、人員、班表內容)上線前請整批置換。
