五間院所共用的月出勤表。醫師走診次制,醫護長與管理部走工時制,合為一個檔案。助理不在本表範圍。

## 為什麼是一個檔

27 位醫師裡有 16 位跨院看診(林智俊院長跑四間)。一院一檔的話,排一位跨院醫師
要開四個檔,而且擋不住「同一診次被排在兩間院所」。改成全體系一個檔後,醫師班表
一格 = 一位醫師的一個診次,格內填院所代碼 —— 一格只容得下一間,衝堂在結構上
不可能發生。

## 九個分頁

`說明` `設定` `醫師週班表` `醫師班表` `醫師月結` `醫護長與管理部班表` `打卡匯入` `出勤紀錄` `月結統計`

### 醫師側的資料流

    醫師週班表 →(公式)→ 醫師班表 →(公式)→ 醫師月結

兩邊改都會立刻反映到月結:改週班表等於改固定門診,整個月跟著變;直接改醫師班表
的格子等於這個月的單次例外。

`醫師班表` 的格子是公式,用 `MATCH` 以員工編號對應到週班表的列,不靠列位置硬綁。
隱藏的輔助列 57~59 存放每一欄的「週班表格號 / 單雙週 / 當日狀態」,輔助欄 CU 存放
每位醫師在週班表的列號 —— 把重複運算抽出來,單格公式才不會長到失控。

使用者打字覆蓋某格時公式會消失、該格從此與週班表脫鉤,因此加了條件式格式
(`_xlfn.ISFORMULA`)把這種格子標上紅色外框。要恢復連動,從鄰近未修改的格子複製
一格貼回即可。

姓名、專科、日期、星期仍是實值,只有班別格是公式。

- **醫師週班表** 官網門診表的固定週輪值,27 位醫師 × 週一到週六 × 早午晚 = 18 格。
  這是母表,月班表由它展開。

- **醫師班表** 40 列 × 93 診次欄(31 天 × 早/午/晚),已依週班表展開為 2026/10。
  底下五列反向檢查各院所每診次的醫師數;休診時段顯示「休」,只有真的沒醫師才標紅。
- **醫師月結** 以診次為單位:五間院所各自診次、總診次、服務院所數、休假診次。
  醫師請假常只請半天,所以不以天數計。
- **醫護長與管理部班表 / 打卡匯入 / 出勤紀錄 / 月結統計** 工時制那一套。七位已建檔:
  醫護長 ivy(晶悅)、文君(晶睿·晶曜)、小玲(晶匯)、娜娜(寶貝牙);
  管理部 孟諭、怡雯、小華(三位都在晶匯)。班表 12 列(7 位 + 5 保留)× 31 天,
  打卡匯入 500 列,出勤紀錄 372 列。
  文君兼管兩間,是**一個員工編號、一份打卡紀錄**,班表只佔一列;
  院所欄寫成「晶睿·晶曜」,底下的人力檢核用包含比對而非完全相等,所以兩間都會算到她。
  一間院所只有一位醫護長,檢核的門檻因此是「當天掛 0 才示警」,不是「少於兩人」。
  檢核列共六列:五間院所各一列 + 管理部一列。院所那五列**只數醫護長**——管理部
  同樣在晶匯上班,但代替不了醫護長,混在一起數會讓「小玲請假、三位管理部在」
  看起來像有人顧,那正是要抓的狀況。

> **⚠ 勞基法第 30 條的正常工時是每日 8 小時。** 「全日」排 9 小時,多出來的 1 小時
> 本質上就是延長工時,但本表的加班是用「實際 − 排班」算的,排進去反而算不出加班。
> 「全日」不宜當成常態班別。

## 班表看板(階段一)

`build_site.py` 產生一頁式靜態網站(輸出為 `上傳這個資料夾/index.html`,整個資料夾拖上 Cloudflare 即可),沒有後端、沒有資料庫,就是一個算好的 HTML。
資料與 Excel 主檔同源:`weekly.py` → `build_roster.py` 的週班表標記與單雙週規則
→ 展開成當月。網站唯讀,要改班表請改 Excel 主檔後重跑。

**為什麼不直接呼叫 `expand_month`**:Excel 的醫師班表是公式驅動的,格子讀週班表的
標記(`悅`、`悅(隔)`、`悅/睿`)再依單雙週解析。`expand_month` 是另一套 Python 實作,
而且在 `build_roster` 裡從未被呼叫,等於沒跟出貨的 Excel 對過帳。網站若用它就成了
第二個真相來源。所以 `build_site.py` 照公式那條路重算,再拿 `expand_month` 當獨立
對照——2511 格全數相符才寫檔,不符就中止。

重跑後另外核對過:網站重建的週班表標記與 Excel `醫師週班表` 的 223 格完全一致;
`grid`(院所→醫師)與 `docm`(醫師→院所)互為反表;週日與週六晚診皆無排診。

    python3 build_site.py

兩個輸出,因為有兩個去處:`班表看板.html` 是完整 HTML 文件,給 Cloudflare Pages
或官網直接託管;`班表看板_預覽.html` 只有內容,給 Artifact 預覽用。

### 腳本的路徑

三支 `build_*.py` 的輸出一律落在**腳本自己所在的資料夾**(`pathlib.Path(__file__).parent`),
不是 cwd、也不是寫死的絕對路徑。先前寫死 `/home/user/-/out/...`,那只在本專案的
沙箱裡成立,打包給別人就會失敗。已實測:把腳本複製到任意資料夾、從無關的 cwd
執行,產出都正確落在腳本旁邊。

## 換月

年月不再寫死在程式裡:

    GEMRAY_PERIOD=2026-11 python3 build_roster.py
    GEMRAY_PERIOD=2026-11 python3 build_site.py

沒給 `GEMRAY_PERIOD` 就用 `build_roster.py` 裡的預設值。天數一律由 `calendar.monthrange`
推算——原本寫死 31,11 月會多出一天(網站端會直接 `ValueError`,Excel 端則靠
`DAY(EOMONTH(...))` 把多的欄位清空)。

非技術人員請用 `更新看板.command`(macOS)或 `更新看板.bat`(Windows),
按兩下、輸入月份即可,會自動檢查 Python 與 openpyxl。
**這兩個啟動檔在本專案的 Linux 環境只驗證過核心流程,未在 macOS/Windows 上實測。**

跨月連續性已驗證:四組隔週輪替醫師在 2026/10–12 的 98 格逐一比對單雙週,不符 0;
國定假日會正確跳過而不打斷輪替節奏。

## 上網前的個資檢查

`verify_privacy.py` 把「出勤紀錄不上網」變成每次都能跑的條件,六項:
頁面文字不含 16 個敏感字眼、資料結構無多餘欄位、醫師資料只有允許的欄位、
班表格子只可能是院所代碼或國/休/空白、沒有診次時間以外的 `HH:MM`、
工時制七位不出現在頁面。現行檔案六項全過。

    python3 verify_privacy.py 班表看板.html

## 為什麼名冊資料寫實值而不用公式

openpyxl 寫出的公式沒有快取值,不會重算公式的檢視器(手機預覽、雲端硬碟預覽、
部分看圖工具)會整欄顯示空白。姓名、專科、職務、日期、星期都是產生時就已知的
靜態資料,因此直接寫入實值;只有空白備用列保留公式,之後填入編號會自動帶出。

統計類欄位(醫師月結、人力檢核、出勤紀錄、月結統計)維持公式 —— 使用者會編輯
班表,寫死成固定數字就不會跟著變。這些欄位在不重算的檢視器裡仍會空白,
用 Excel 或 Google 試算表正式開啟即可,必要時按 Ctrl+Alt+F9 強制重算。

## 設計約束

- 有固定時段的班別代碼必須滿足 `應退 − 應到 − 休息 = 排班工時`,建置腳本會 assert 檢查。
- 加班採門檻制(預設 30 分認定、30 分為單位、遲到早退寬限 5 分)。逐分鐘認定會把
  每天正常收尾的十幾分鐘全算成加班(實測:45.6 小時 vs 6.5 小時)。參數集中在 `設定`。
- 加班時數為「實際工時 − 排班工時」,**未依勞基法第 24 條換算費率**。
- `出勤紀錄` 為第 30 條的逐日紀錄,**必須每月另存唯讀封存檔**(法定保存 5 年)。

## 待核對(會影響排班正確性)

1. **2026 國定假日為草稿**。法定紀念日日期可信度高,但補假與調整放假
   (彈性放假)每年由人事行政總處公告,務必與官方「政府行政機關辦公日曆表」核對。
   表在 `設定` 分頁 W:Y 欄,共 21 天。
2. **隔週互換方向未知**。四組互換(王泳泉週一、劉立德週三、朱柏非與陳昺元週六)
   以固定基準日(`ALT_EPOCH`,2026/9/28)起連續數週判定單雙,跨月跨年不會斷。
   哪一組先待院所確認 —— 確認後把基準日挪一週即可整體對齊。
3. **陳爵安、吳冠廷、楊孟庭**三位只出現在門診表,官網名單沒有,已暫編 D025~D027。
4. 官網門診表星號註記(非每週固定)共 9 處,需向院所逐一確認。

## 待補

1. 工時制七位的**到職日**,缺了算不出特休年資。
2. 組合班別(早午、午晚、早晚、全日)是推的。體系以早/午/晚三診次計算已確認,
   但一格一天裝不下兩個診次,所以加了組合代碼 —— 實際是不是這樣排需院所確認。
3. 員工編號 D001~D027 / N001~N004 / M001~M003 為暫編,若人事或打卡系統另有編號應以那套為主鍵。
4. 本檔是**單月檔**,年月寫死在 `build_roster.py` 的 `YEAR, MONTH`。日期與星期是實值,
   改 `設定` 的年月不會自動改班表 —— 換月請改腳本重跑。


## 重建

```bash
pip install openpyxl
python3 build_roster.py                  # 完整版(9 分頁)
python3 build_roster.py --no-assistant   # 醫師版(5 分頁)
```

工時制的四個分頁彼此相依:出勤紀錄讀醫護長與管理部班表與打卡匯入,月結統計讀出勤紀錄。
只拿掉其中一頁會讓其餘變成 `#REF!`,所以 `--no-assistant` 是整組拿掉,
並同步調整說明分頁與人員名冊中指向那四頁的內容。
