# 日三牙醫體系 統一出勤表

五間院所共用的月出勤表。醫師走診次制、助理與醫護長走工時制,合為一個檔案。

| 檔案 | 說明 |
| --- | --- |
| `日三牙醫體系_統一出勤表.xlsx` | 主檔。8 個分頁,已灌入 5 間院所與 24 位醫師。 |
| `roster-spec.html` | 規格說明頁,給上級與各院所溝通用。 |
| `todo.html` | 上線前待辦清單(28 項),可勾選,狀態存在頁面本身。 |
| `build_roster.py` | 產生 xlsx 的腳本。改名冊或代碼表後重跑即可重建。 |
| `醫師名單.csv` | 從官網醫療團隊頁解析出的醫師名單與跨院對照。 |
| `門診表轉錄核對.csv` | 五間院所門診表的轉錄結果,239 列,供逐格核對。 |
| `weekly.py` | 門診表結構化資料(週固定輪值 + 診次時間),`build_roster.py` 由此展開月班表。 |

## 為什麼是一個檔

27 位醫師裡有 16 位跨院看診(林智俊院長跑四間)。一院一檔的話,排一位跨院醫師
要開四個檔,而且擋不住「同一診次被排在兩間院所」。改成全體系一個檔後,醫師班表
一格 = 一位醫師的一個診次,格內填院所代碼 —— 一格只容得下一間,衝堂在結構上
不可能發生。

## 九個分頁

`說明` `設定` `醫師週班表` `醫師班表` `醫師月結` `助理班表` `打卡匯入` `出勤紀錄` `月結統計`

- **醫師週班表** 官網門診表的固定週輪值,27 位醫師 × 週一到週六 × 早午晚 = 18 格。
  這是母表,月班表由它展開。

- **醫師班表** 40 列 × 93 診次欄(31 天 × 早/午/晚),已依週班表展開為 2026/10。
  底下五列反向檢查各院所每診次的醫師數;休診時段顯示「休」,只有真的沒醫師才標紅。
- **醫師月結** 以診次為單位:五間院所各自診次、總診次、服務院所數、休假診次。
  醫師請假常只請半天,所以不以天數計。
- **助理班表 / 打卡匯入 / 出勤紀錄 / 月結統計** 工時制那一套,結構已建好,
  待助理與醫護長名單灌入。

## 設計約束

- 有固定時段的班別代碼必須滿足 `應退 − 應到 − 休息 = 排班工時`,建置腳本會 assert 檢查。
- 加班採門檻制(預設 30 分認定、30 分為單位、遲到早退寬限 5 分)。逐分鐘認定會把
  每天正常收尾的十幾分鐘全算成加班(實測:45.6 小時 vs 6.5 小時)。參數集中在 `設定`。
- 加班時數為「實際工時 − 排班工時」,**未依勞基法第 24 條換算費率**。
- `出勤紀錄` 為第 30 條的逐日紀錄,**必須每月另存唯讀封存檔**(法定保存 5 年)。

## 診次時間

晶悅 / 晶睿 / 晶匯 / 晶曜:早 09:00–11:30、午 14:00–16:30、晚 18:00–20:30
寶貝牙:早 09:00–14:00、午 14:00–17:00、晚 17:30–21:00,且週一至週五早診休診

五間院所週日全休、週六晚診全休。班表的「早/午/晚」只是時段代號,實際時間依院所而定,
對照表在 `設定` 分頁的院所清單(含 18 格開診時段旗標)。

## 待核對(會影響排班正確性)

1. **門診表為截圖轉錄**,239 格逐字打入,姓名與隔週標記可能有誤。
   若能提供五個門診表頁面的網頁存檔,可完全免除轉錄誤差。
2. **隔週互換方向未知**。四組互換(王泳泉週一、劉立德週三、朱柏非與陳昺元週六)
   以固定基準日(`ALT_EPOCH`,2026/9/28)起連續數週判定單雙,跨月跨年不會斷。
   哪一組先待院所確認 —— 確認後把基準日挪一週即可整體對齊。
3. **陳爵安、吳冠廷、楊孟庭**三位只出現在門診表,官網名單沒有,已暫編 D025~D027。

## 待補

1. 助理與醫護長名單。
2. 助理班別時間(目前為暫定值)。
3. 員工編號 D001~D027 為暫編,若人事或打卡系統另有編號應以那套為主鍵。
4. 官網門診表星號註記者(並非每週固定)需向院所逐一確認。
